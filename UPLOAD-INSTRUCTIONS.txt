THIS UPDATE FIXES JARVIS'S VOICE ON PHONES

The earlier site used the phone/browser's built-in speechSynthesis voice.
That is why the hologram activated but JARVIS could remain silent on mobile.

This version generates a real WAV response using Gemini TTS and plays it
through a persistent audio element that is unlocked when you tap Activate.

UPLOAD

1. Extract this ZIP.
2. Open the extracted folder.
3. Open your GitHub testsite repository.
4. Click Add file > Upload files.
5. Drag EVERYTHING inside the extracted folder into GitHub.
6. Confirm the api folder contains:
      chat.js
      youtube.js
      tts.js
7. Commit the update.
8. Wait for Vercel's newest deployment to say Ready.
9. Fully close the browser tab on your phone.
10. Reopen the site and tap Activate Voice Assistant.
11. Say:
      JARVIS, tell me who you are.

NO NEW API KEY IS REQUIRED.

The existing GEMINI_API_KEY powers both chat and voice.

TEST THE TTS ROUTE

Open:
https://www.simplytestsite.com/api/tts

Expected JSON includes:
"status": "ok"
"apiKeyConfigured": true

If your phone still blocks audio, the site displays:
Tap to Enable JARVIS Voice

Tap that button once.
